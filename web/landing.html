How the airgap works

Five parts between a page and your wallet.

  1. Fetcher

    core/fetcher.py

    Code records where the page came from.

  2. Sanitizer

    core/sanitizer.py

    Code strips text a browser hides.

  3. Reader

    core/reader.py

    A model with no tools returns typed, untrusted fields.

  4. Planner

    core/orchestrator.py

    A model sees your request, never the page.

  5. Policy

    core/policy.py

    Code decides every payment and email, to payees on your list.
